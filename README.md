# ShopEase Luxe 👗💄✨

A modern luxury fashion & beauty e-commerce boutique application built with **Flutter** and **Provider**.

## ✨ Features
- **Curated Collections**: Dresses, Makeup, Skincare, and Accessories.
- **Micro-Animations**:
  - Staggered card entrance fade & slide effects.
  - Interactive hover lift & shadow glow.
  - Elastic scale heart/favorite wishlist animation.
  - Smooth Hero transitions between catalog grid and detailed product views.
  - Auto-sliding promotional carousel with animated page indicators.
  - Animated cart badge feedback.
- **Dynamic Filtering & Search**: Instant real-time search across brands, items, and categories.
- **Interactive Details**: Color/shade selection swatches, size selection pills, and quantity stepper.
- **Shopping Bag & Checkout**:
  - Live subtotal and free shipping progress tracker.
  - Coupon discount system (`GLAM20` for 20% off).
  - Multi-method checkout (Cards, Digital Wallets, Cash on Delivery) with address verification and success dialog.

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (>= 3.0.0)
- Google Chrome (for web) or an Android / iOS device / desktop emulator.

### Run Locally

1. Install dependencies:
   ```bash
   flutter pub get
   ```

2. Run in Chrome (Web):
   ```bash
   flutter run -d chrome
   ```

3. Run on Windows desktop:
   ```bash
   flutter run -d windows
   ```
